4 Lifecycle Hooks — registered in plugin.json

Intercept tool calls before they run. They make the autonomous, background-spawned agents possible.
PreToolUse · Write|Edit
validate-dbt-structure.py
Enforces dbt file naming & placement before any model is written.
PreToolUse · Bash
approve-plugin-bash.py
Auto-approves plugin-internal scripts (allowlist) so background agents never stall on a permission prompt.
WorktreeCreate
create-worktree.py
Sets up an isolated git worktree (isolation is OFF by default).
WorktreeRemove
remove-worktree.py
Cleans up the worktree on teardown.

userConfig — set at install time

Connection settings provided once, then injected into every subprocess as CLAUDE_PLUGIN_OPTION_* env vars.
→ MCP env
sql_server · sql_database · sql_auth_type
Feed the ${user_config.*} bindings in the MCP server block.
→ skills
sql_user · sql_password*
Python skills read these via _load_plugin_userconfig_env(). * sensitive → system keychain.
→ entra
azure_tenant_id · client_id · client_secret*
Service-principal auth for Azure SQL via the MCP server.
